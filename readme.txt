=== Cort AI Studio ===
Requires at least: 6.5
Requires PHP: 8.1
Stable tag: 1.2.0

Generate editable WordPress blog drafts with OpenAI, optional research and images, and usage tracking.
Create and edit native classic/Flexbox Elementor pages through reviewed draft previews, explicit approval, and operation backups. Atomic V4 authoring is not included.
New pages and sections include visual planning, native design systems, responsive compositions, contextual media selection and deterministic design checks.

== Installation ==

1. Upload the Cort AI Studio ZIP under Plugins > Add New > Upload Plugin.
2. Activate Cort AI Studio.
3. Go to Cort AI Studio > Settings, save an OpenAI API key, and select Test Connection.
4. Complete the Website Content Profile and create a draft in AI Blog Writer.

See README.md for setup, architecture, verification, and recovery details.
